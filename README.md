# Telegram Mini App: магазин

Тёмный дизайн: крупные скруглённые карточки, оливковый акцент, плавающая навигация. Каталог с поиском и категориями → карточка товара с размерами → избранное → корзина → оформление (адрес, способ оплаты) → экран «Заказ оформлен». Заказ приходит администратору в Telegram, покупателю — подтверждение от бота.

- **Фронтенд:** React + Vite, подстраивается под светлую/тёмную тему Telegram, использует MainButton, BackButton и вибрацию.
- **Бэкенд:** serverless-функции Vercel (`/api/bot` — webhook бота, `/api/order` — приём заказов).
- **Безопасность:** подпись `initData` проверяется на сервере, сумма заказа пересчитывается по серверному каталогу.
- **Хостинг:** бесплатный тариф Vercel (Hobby).

## Структура

```
shared/products.js   ← каталог товаров (редактировать здесь)
shared/config.js     ← название, слоган, валюта, доставка
src/styles.css       ← цвета и стили (переменные в :root)
src/                 ← интерфейс мини-аппа
api/bot.js           ← webhook бота (/start, /id)
api/order.js         ← приём и отправка заказа
scripts/setup-bot.mjs← регистрация webhook и кнопки меню
```

## Запуск за 10 минут

### 1. Создайте бота
В [@BotFather](https://t.me/BotFather): `/newbot` → сохраните **токен**.

### 2. Залейте код на GitHub
```bash
git init && git add . && git commit -m "init"
# создайте пустой репозиторий на github.com и:
git remote add origin https://github.com/<you>/tg-shop.git
git push -u origin main
```

### 3. Задеплойте на Vercel
1. [vercel.com](https://vercel.com) → войти через GitHub → **Add New → Project** → выберите репозиторий.
2. Framework определится как **Vite** автоматически.
3. В **Environment Variables** добавьте:
   - `BOT_TOKEN` — токен бота
   - `WEBHOOK_SECRET` — любая случайная строка (латиница/цифры)
   - `ADMIN_CHAT_ID` — пока поставьте `0`, заполним на шаге 5
   - `WEBAPP_URL` — заполните после первого деплоя адресом вида `https://tg-shop-xxx.vercel.app`
4. **Deploy**. После деплоя впишите `WEBAPP_URL` и сделайте **Redeploy**.

### 4. Подключите бота к приложению
Локально (нужен Node 18+):
```bash
BOT_TOKEN=... WEBAPP_URL=https://tg-shop-xxx.vercel.app WEBHOOK_SECRET=... npm run setup-bot
```
Скрипт настроит webhook, кнопку «Магазин» у поля ввода и команды.

### 5. Укажите, куда слать заказы
Напишите боту `/id` (или добавьте бота в группу менеджеров и напишите `/id` там) → скопируйте число в `ADMIN_CHAT_ID` на Vercel → **Redeploy**.

Готово: откройте бота, нажмите «Магазин» и оформите тестовый заказ.

## Локальная разработка
```bash
npm install
npm run dev
```
В обычном браузере вместо кнопки Telegram показывается своя кнопка. Оформить заказ так нельзя: сервер требует подпись Telegram, поэтому тестируйте заказы уже через бота.

## Что можно доработать
- **Фото товаров:** сейчас вместо фото линейные иллюстрации. Положите фото (лучше PNG без фона, квадрат 800×800) в `public/img/` и укажите в товаре `image: '/img/parka.png'`.
- **Хранение заказов:** сейчас заказы только отправляются в Telegram. Для истории подключите бесплатную БД (Vercel Postgres/Neon, Supabase).
- **Онлайн-оплата:** Telegram Payments (`createInvoiceLink` + `tg.openInvoice`) или Telegram Stars для цифровых товаров.
- **Варианты товаров:** размеры и цвета.
